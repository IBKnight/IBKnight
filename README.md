## Featured projects

**[posts-statistic-service](https://github.com/IBKnight/posts-statistic-service)** — real-time post statistics service in Go.
Kafka consumer with partition-based sharding (Kubernetes StatefulSet), event deduplication for at-least-once delivery, snapshot backup/restore to MinIO, graceful shutdown, Prometheus metrics and a provisioned Grafana dashboard, synthetic traffic generator.

**[Inbetween](https://github.com/IBKnight/Inbetween)** — frame generation tool in pure Go (no cgo).
D3D11/DXGI through hand-written COM calls, GPU optical flow in HLSL with shader hot reload, frame pacing, automated release builds.

**[repository-map](https://github.com/IBKnight/repository-map)** — CLI that maps a repository and scaffolds instruction files for AI coding agents (Claude Code, Copilot, Cursor, AGENTS.md). CI + GoReleaser cross-platform releases.

**[yeast-starter](https://github.com/IBKnight/yeast-starter)** — multi-module Android starter template with Gradle convention plugins, layered core modules and feature modules.
